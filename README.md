# Handy Parser

Лёгкий мониторинг цен и других значений на веб-страницах с уведомлениями в Telegram.

**Статус: ранняя alpha.** Рабочий первый срез уже реализован: HTML/CSS и PSP-парсинг, профиль GPC, SQLite, правила изменения цены, надёжная очередь Telegram, защищённая веб-панель и разовая команда проверки. Каждый коммит основной ветки собирается в публичный multi-arch образ `ghcr.io/expressionist/handy-parser:edge`. До первого стабильного релиза остаются проверка на Debian 13, реальная отправка в Telegram и замеры на VPS.

## Задача

- Debian 13, VPS с 2 CPU и 2 ГБ RAM, около 800 МБ свободно; на сервере уже работают другие приложения.
- До 10 наблюдений, четыре проверки в сутки, возможность запуска вручную.
- URL и CSS-селекторы можно вводить вручную; для PSP предусмотрен встроенный обработчик API.
- Небольшая веб-панель: настройка, предпросмотр значения, статус и история.
- Telegram: старое и новое значение, ссылка; отдельные уведомления о длительной недоступности источника.
- Установка через Docker Compose, хранение данных вне контейнера.

## Выбранный подход

Go + SQLite. Один небольшой контейнер `serve` держит веб-панель и встроенный планировщик. Четыре раза в сутки он последовательно проверяет страницы тем же runner, который используется кнопкой ручного запуска. Дополнительные контейнеры, cron и systemd timer не требуются; между проверками планировщик ожидает таймер и практически не использует CPU.

Chromium, Redis, отдельный сервер БД и постоянно работающий Telegram-бот в первой версии не требуются. Изменение наблюдения и кнопка ручной проверки доступны в панели. Ручная проверка использует то же ядро проверки и блокировку, что и команда `check`.

## Локальный запуск для разработки

Требуется Go 1.27:

```sh
go test ./...
go build -o handy-parser ./cmd/handy-parser
HANDY_ADMIN_PASSWORD='replace-me' ./handy-parser serve
```

По умолчанию база создаётся в `data/handy.db`. При установке через Docker все пользовательские настройки находятся в `.env`: пароль панели, Telegram token/chat ID, внешний адрес и порт. Docker собирает образ непосредственно из исходников репозитория; полный порядок описан в инструкции установки.

## Быстрый запуск через Docker

```sh
git clone https://github.com/eXpressionist/handy-parser.git
cd handy-parser
cp .env.example .env
nano .env
sudo install -d -o 10001 -g 10001 -m 0700 data
sudo docker compose up -d --build web
```

После запуска панель доступна по адресу `http://IP_СЕРВЕРА:HANDY_WEB_PORT`. Перед открытием порта для всего интернета настройте firewall или HTTPS reverse proxy.

## Порядок работы

1. Проверить встроенный планировщик и перезапуск контейнера на Debian 13.
2. Проверить реальную отправку в Telegram.
3. Измерить память на целевом VPS.
4. Выпустить первый неизменяемый тег с образом в GHCR.

Подробные выполненные и оставшиеся задачи перечислены в [плане реализации](docs/IMPLEMENTATION_PLAN.md). Alpha-код пригоден для разработки и тестирования; установку на рабочий VPS лучше выполнять после первого помеченного релиза.
